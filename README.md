# Creative Embedded Systems

Kira Dabbagh’s course documentation for COMS BC 3930, Fall 2026.

This repository contains the public course landing page, with an introduction, learning goals, and a project journal that will grow throughout the semester.

## Updating the site

Edit `index.html` to update the introduction or add project entries. Each future project should link to its process write-up and its own code repository/README, including components, setup instructions, media, and acknowledgments.

## Local preview

Run `python3 -m http.server 8080` in this folder, then visit http://localhost:8080.

## Course separation

This repository belongs under `keira-columbia` and is exclusively for Creative Embedded Systems. It is separate from GEAI and all other coursework.
